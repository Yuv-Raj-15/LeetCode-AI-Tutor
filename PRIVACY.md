# Privacy Policy for LeetCode AI Tutor

**Last Updated:** May 2026

This Privacy Policy explains how the LeetCode AI Tutor browser extension ("the Extension") handles user data. Our core philosophy is to collect the absolute minimum amount of data necessary to provide you with debugging assistance.

## 1. Data We Do Not Collect
* **No Personal Information:** We do not collect, store, or request your name, email address, LeetCode account details, or any identifying information.
* **No Tracking:** We do not use cookies, analytics, or tracking scripts to monitor your browsing behavior.

## 2. Data We Process
To function, the Extension must read the code you have currently typed into the LeetCode code editor. 

* **How it works:** When you click "Get Hint" or "Fix Code", the Extension reads the text inside the LeetCode editor.
* **Third-Party Transmission:** This code snippet, along with the problem context, is transmitted securely to the **OpenRouter API** to generate the AI response. 
* **No Retention:** The Extension itself does not save, log, or retain your code snippets after the AI response is generated. 

## 3. Third-Party Services
We use the OpenRouter API to process the code snippets and generate AI hints. Please refer to OpenRouter's privacy policy to understand how they handle API requests.

## 4. Your API Key
The Extension requires you to input your own OpenRouter API key. This key is stored locally on your device within your browser's local storage. It is never transmitted to our servers (because we don't have any) and is used exclusively to authenticate your requests with OpenRouter.

## 5. Contact
If you have any questions or concerns about this privacy policy or the extension's code, please open an issue on our GitHub repository.
